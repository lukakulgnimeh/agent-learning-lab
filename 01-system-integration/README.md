## System integration - my first agentic project
The goal of this first project is to get my hands on AI agents featuring simple API integrations. I decided to do that with a locally hostet version of n8n to learn the principles without losing myself in code immediately. So as expected, the first obstacles arose in the installation process regarding docker, terminal use etc. Anyways. 

Different from future projects, this one does not carry any documentation on architecture, system flow and execution, decisions and potential problems. All these things were carried out in a rich mental model, which I initially fine-tuned so well, that the actual construction started rather late in, but went extremly smoothly and fast - including all changes that had to be done. 

Nevertheless, the project folder includes:
* The prompts and nodes which are written in german since I do not wanted to lose thought to perfect formulations. Of course, the precise configurations of the nodes are missing, unfortunately.
* A snapshot of the constructed workflow.
* An evaluation of the resulting workflow and a reflection on what I have learned.
