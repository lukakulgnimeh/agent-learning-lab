## System integration - my first agentic project
The goal of this first project is to familiarize myself with AI agents using simple API integrations. I decided to do this with a locally hosted version of n8n to learn the basics without getting lost in the code right away. As expected, the first hurdles cropped up during the installation process, involving Docker, using the terminal, and so on.

Unlike future projects, this one does not include documentation on the architecture, system workflow and execution, decision-making, or potential issues. All of these aspects were worked through in a comprehensive mental model that I had refined so thoroughly at the outset that, although the actual implementation began relatively late, it proceeded extremely smoothly and quickly - including all the changes that had to be made.

Nevertheless, the project folder includes:
* The prompts and nodes, which are written in German, since I didn’t want to lose my train of thought by searching for perfect phrasing. Unfortunately, the exact configurations of the nodes are missing, of course.
* A snapshot of the constructed workflow.
* An evaluation of the resulting workflow and a reflection on what I learned.
