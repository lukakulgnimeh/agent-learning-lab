# Modules and Components of Agent Systems

| Module / Component | Responsibility                                                                                               | Inputs                                          | Outputs                                                 |
| ------------------ | ------------------------------------------------------------------------------------------------------------ | ----------------------------------------------- | ------------------------------------------------------- |
| Cache              | Stores frequently used results to reduce latency and computational cost.                                     | Query, computation result                       | Cached response or retrieved cached value               |
| Chunker            | Splits documents into meaningful chunks for indexing and retrieval.                                          | Raw document                                    | Document chunks                                         |
| Context Window     | Holds all information currently visible to the language model during inference.                              | Prompt, retrieved context, conversation history |                                      |
| Embedding Model    | Converts text into dense vector representations for semantic comparison.                                     | Text                                            | Embedding vector                                        |
| Execution          | Represents a single run of a workflow or agent system.                                                       | Trigger, workflow input                         | Workflow execution state and outputs                    |
| LLM                | Generates natural language, performs reasoning, planning, and decision making based on the provided context. | Prompt, context, retrieved documents            | Natural language response or structured output          |
| Logger             | Records events, decisions, errors, and execution traces for monitoring and debugging.                        | Events, system actions                          | Log entries                                             |
| MCP Server         | Exposes tools through a standardized interface independent of their implementation.                          | Tool requests                                   | Tool responses                                          |
| Memory             | Stores conversational or agent state across interactions (short-term or long-term).                          | Messages, observations, results                 | Retrieved memories or updated memory                    |
| Metadata           | Describes documents or chunks with structured attributes for filtering, tracing, and citation.               | Document information                            | Structured metadata (e.g., source, page, chapter, date) |
| Parser             | Extracts and structures information from unstructured input.                                                 | Raw text, files, API responses                  | Structured data                                         |
| Prompt Template    | Defines reusable prompt structures with placeholders for dynamic inputs.                                     | Variables, instructions                         | Final prompt                                            |
| Retriever          | Retrieves the most relevant documents or chunks based on a query.                                            | Query embedding or search query                 | Retrieved documents                                     |
| Reranker           | Reorders retrieved documents according to estimated relevance.                                               | Retrieved documents, query                      | Ranked document list                                    |
| Router             | Directs requests, tasks, or data to the appropriate component based on predefined rules or model decisions.  | Request, workflow state                         | Routed request or selected path                         |
| Session            | Groups multiple interactions belonging to the same user conversation or task.                                | User interactions                               | Session state                                           |
| State              | Represents the current working state of an agent or workflow during execution.                               | Intermediate results, variables                 | Updated system state                                    |
| Tool               | Provides external capabilities beyond the language model, such as APIs or databases.                         | Tool request                                    | External result                                         |
| Trigger            | Initiates the execution of a workflow or agent process.                                                      | External event, user action, schedule           | Workflow start                                          |
| Validator          | Verifies that data, outputs, or inputs satisfy required formats or constraints.                              | Structured or unstructured data                 | Validation result or corrected data                     |
| Vector Database    | Stores embeddings and enables efficient similarity search over vector representations.                       | Embedding vectors, metadata                     | Matching vectors or retrieved documents                 |
| Webhook            | Sends or receives events between systems via HTTP endpoints.                                                 | HTTP request or event                           | Triggered event or HTTP response                        |
